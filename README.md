# Barbaros Zorlu — Portfolio

A production-ready static portfolio built with semantic HTML5, Tailwind CSS via CDN, and vanilla JavaScript.

## Files

- `index.html` — complete website
- `.nojekyll` — disables Jekyll processing on GitHub Pages
- `README.md` — deployment notes
- `resume.pdf` — **add your resume with this exact filename** so the Resume button works

## GitHub Pages deployment

1. Create a new **public** repository on GitHub.
2. Upload the files in this folder to the repository root.
3. Add your actual resume as `resume.pdf`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose **main** and **/ (root)**, then save.

For a root personal site, name the repository `barbarosz.github.io`.

## External resources

The site uses:
- Tailwind CSS via CDN
- Google Fonts (Inter + JetBrains Mono)
- Simple Icons CDN for a small set of technology/company icons

No build step or npm install is required.
